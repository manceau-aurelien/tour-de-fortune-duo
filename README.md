# 🏰 Tour de Fortune · Duo

Jeu de défense de tour coopératif à deux, dans le navigateur.

- **🏹 La Tour** : vous tenez l'arc au sommet de la tour. Maintenez le clic pour bander l'arc, relâchez pour tirer.
- **🃏 L'Invocateur** : vous piochez des cartes, fusionnez les paires pour monter leur rang, et posez combattants et sorts sur le terrain.

Deux niveaux de 5 vagues, chacun terminé par un boss. Chaque rôle a son propre arbre de compétences.

## Jouer

Ouvrez la page du jeu, cliquez sur **⚔ Jouer** puis :

- **Avec une IA** : l'autre rôle est tenu par l'ordinateur ;
- **Créer une partie en ligne** : vous recevez un code de 4 lettres à donner à votre partenaire ;
- **Rejoindre un ami** : tapez le code reçu.

Le jeu en ligne passe par [PeerJS](https://peerjs.com/) : les deux navigateurs se connectent directement, sans serveur de jeu.

## Commandes

`Espace` prêt pour la vague · `clic droit` signaler un endroit · `Q` / `E` sorts de la tour · `Échap` annuler
